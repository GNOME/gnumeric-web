Gnumeric 1.12.62 aka "TBD" is now available.

The Gnumeric Team is pleased to announce the availability of Gnumeric version 1.12.62.

Noteworthy news in this release:

  • New functions.
  • Improved xl compatibility.
  • Fix a few bugs affecting users using Wayland.
  • Work around some bugs in Wayland.

Details of changes by contributor:

  • Morten
    • Test improvements.
    • New function PHI.
    • New function GAUSS.
    • New function PERCENTOF.
    • New function REGEXTEST.
    • New function REGEXEXTRACT.
    • New function REGEXREPLACE.
    • New functions NETWORKDAYS.INTL and WORKDAY.INTL.
    • New functions PARTITIONS.
    • Add export option "formulas=true" to txt and csv.
    • Improve xlsx export.
    • Improve xl compatibility for multiple functions.
    • Improve GEOMEAN accuracy.
    • Fix problem with sylk importer. [Bug 878].
    • Improve xl compatibility for complex functions.
    • Fix problems with blanks for database functions. [Bug 887].
    • Fix auto-filter problem. [Bug 891].
    • Avoid Wayland auto-filter warnings.
    • Eliminate reliance on deprecated pango functions.
    • Eliminate reliance on deprecated python functions.
    • Fix R.PST in the log case.

goffice 0.10.62 aka "TBD" is now available.

The Gnumeric Team is pleased to announce the availability of goffice version 0.10.62. This is a bugfix release.

Details of changes by contributor:

  • Ismael Luceno
    • Use C99 isfinite()/isnan() instead of BSD legacy ones.
    • Reject -ffast-math and -ffinite-math-only.
    • Fix build on musl, which lacks isnanl().
    • Rename finiteD() to isfiniteD(). [--with-decimal64].
  • Morten
    • Plug leaks.
    • Fix pango markup issues.
    • Fix pixbuf problem. [Bug 892] [Bug 886].
    • Tentative fix for [Bug 896] (via claude.ai).
